Simulador desenvolvido pela equipe MecaTiger para testar rotinas e movimentos FTC em uma arena virtual.

PRÉVIA INTERATIVA
DO MECA SIM.

Esta prévia web permite explorar a arena BIOBUZZ e desenhar trajetórias simples no navegador. Ela é demonstrativa e não inclui o simulador completo. A demonstração gratuita abre no navegador após entrar com uma conta confirmada. A versão local completa é fornecida pela equipe mediante solicitação por e-mail.

A prévia não executa Java, não aceita código nem uploads e não simula física, sensores ou teleoperação. A versão completa local compila e executa Java com as permissões da sua conta; use somente código confiável.

SOLICITAR VERSÃO COMPLETA.

O MecaSim completo é um programa separado para computador e não roda dentro do navegador. Para manter a distribuição acompanhada pela equipe, ele não é liberado automaticamente pelo site.

Envie a solicitação com seu nome, escola ou equipe, cidade/estado, objetivo de uso e sistema operacional. A equipe responde com as orientações e o material disponível.
